FILE: KEYS_AND_ROOMS.LOG

00. PROBLEM DESCRIPTION

There are n rooms labeled from 0 to n - 1. All rooms are locked except for room 0. Your goal is to visit all the rooms. However, you cannot enter a locked room without having its key.

When you visit a room, you may find a set of distinct keys in it. Each key unlocks a specific room; you can take all keys found to unlock further rooms.

01. TEST_CASES

Example 1: 
Input: rooms = [[1],[2],[3],[]]
Output: true
Explanation: Visit 0 -> get key 1 -> visit 1 -> get key 2 -> visit 2 -> get key 3 -> visit 3.
Example 2: 
Input: rooms = [[1,3],[3,0,1],[2],[0]]
Output: false
Explanation: Room 2 is unreachable; its only key is inside itself.

02. CONSTRAINTS

  • n == rooms.length
  • 2 <= n <= 1000
  • 0 <= rooms[i].length <= 1000
  • The sum of rooms[i].length is ≤ 3000.

03. LOW-MEMORY USAGE SOLUTION (C++)

Of course we could solve the problem using a set to store visited rooms and just perform a DFS.

However, using a bitset we can solve the problem while using a minimum amount of memory.

We only need n bits to store our visited rooms.

This is the idea:

1. Let n = 4.

2. Our bitset is initialised as 1000 because the first room is always considered visited.

3. For every unvisited room, we perform a DFS recursively.

4. After the full traversal, if all rooms were visited, then our bitset will be 1111.

5. If the number of ones in our bitset equals n, it means all rooms were visited and we return true; false otherwise.

Neat!

class Solution {
    void dfs(int room, std::bitset<1000>& visited, vector<vector<int>> const& rooms) {
        visited.set(room);
        for (auto const& key : rooms[room]) {
            if (!visited.test(key)) {
                dfs(key, visited, rooms);
            }
        }
    }

public:
    bool canVisitAllRooms(vector<vector<int>>& rooms) {
        auto const n = rooms.size();
        std::bitset<1000> visited;
        dfs(0, visited, rooms);
        return visited.count() == n;
    }
};
